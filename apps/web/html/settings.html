    Khóa API

    Không bắt buộc mua ChatGPT Plus/Pro. Bạn có thể dùng khóa API cá nhân hoặc khóa dùng chung do quản trị viên cấu hình. Để thử model miễn phí qua OpenRouter, vẫn cần khóa OpenRouter và tuân theo hạn mức của nhà cung cấp.

      Tài khoản ChatGPT qua OpenCode

      Kết nối này phụ thuộc quyền truy cập model của tài khoản ChatGPT và cấu hình máy chủ. Bạn cũng có thể sử dụng khóa API ở phần trên, không cần kết nối ChatGPT.
